Why this isn't a "99% accurate" model

Most public models on this dataset report R² above 0.99. That comes from a random train/test split: the data repeats each country-crop-year with different weather-station temperatures, so most of the test rows have an exact twin in training. CropCast is scored on seasons it has never seen.
